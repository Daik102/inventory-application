# Project: Inventory Application

An inventory app with several features<br>
This project is based on **[The Odin Project](https://www.theodinproject.com)**.

## Live Demo

**https://inventory-application-4jio.onrender.com/**

> ⚠️ This project is hosted on a free Render tier. It takes roughly 20–30 seconds for the initial page load.

### Features

- Full CRUD Inventory Management with PostgreSQL

- Interactive UI (Live Search, Type Filtering, and Column Sorting)

- Retro RPG UI

- express-validator for server side validation

### Tech Stack

* **Frontend:** EJS, CSS, JavaScript

* **Backend:** Node.js, Express, express-validator

* **Database:** PostgreSQL, node-postgres (pg)

* **Deployment:** Render, Neon
